= BoJ Server MK2 — Archived
:toc: macro

*Archived on 7 September 2026.* Development is concentrating on the original
https://github.com/hyperpolymath/boj-server[BoJ server] and the canonical
https://github.com/hyperpolymath/boj-server-cartridges[BoJ cartridge registry].

This public archive preserves an experimental architecture proposal and its
reference material. It is not a supported replacement for the original server.

== Why we are concentrating on the original

The original BoJ server already contains an Elixir/OTP host, supervision,
cartridge dispatch, and working protocol components. Our priority is to make
those execution paths dependable, verify advertised cartridge capabilities,
and improve the existing architecture incrementally.

The MK2 proposal coupled several changes: a new host, universal Idris2/Wasm
cartridge execution, Cap'n Proto at the guest boundary, and a rewrite of
cartridge side effects. The implementation and comparative evidence do not
currently justify that combined migration effort.

Useful ideas from this exploration — explicit execution contracts,
host-authorised effects, resource limits, and selective Wasm isolation — may
still be adopted in the original projects when their benefits are demonstrated.
They do not require a wholesale cartridge rewrite.
